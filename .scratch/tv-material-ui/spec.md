# TV 的 Material 3 视觉升级

2026-10-13：用户希望用 Jetpack Compose 达到现代 Android Material 3 观感，并要求推进下一步。本工作沿用现代化 P1–P9 的数据与播放架构，先交付主题、共用控件、首页与设置样板。任务：[01](issues/01-theme-home-settings.md)。

## 保留与可调整范围

- 保留 C 首页：顶部导航、推荐大图与信息并列、继续观看；搜索键盘仍在左侧。
- 保留入口、数据含义、配置 / 设置缺省值、遥控器确认 / 返回、源协议、原播放器 / 直播控制逻辑，Android 9+ 与 ARMv7。
- 允许统一配色、字体层级、圆角、间距、设置分组与焦点样式。设置选项完整映射到旧动作，布局以电视可扫描性组织。
- 视觉验收按这份新规范与操作闭环，不再要求候选与旧画面逐像素相同。旧截图用于解释改动范围与回退。
- 后续页面分批推广，首页 / 设置样板不代表 P4 或 P5 完成。完整播放服务与内核迁移仍按原阶段执行。

## 第一组视觉规范

1. `androidx.tv.material3` 是交互控件与主题所有者，Compose Foundation 负责布局。沿用已通过构建的依赖组合。
2. 暖色系为基线，浅 / 深色分别提供完整语义色；背景、普通容器、强调容器、主次文字与焦点描边有清楚层次。兼容 View 使用同一 XML 色值。
3. 字体分为展示标题、页面标题、章节标题、正文、辅助信息、按钮标签。首页和设置采用新分档；尚未迁移的详情文本继续使用原字体度量，避免扩大本切片。
4. 导航 / 操作采用胶囊，推荐图片采用圆角矩形；设置按类别显示圆角分组。焦点有明确描边与容器色，放大仅在空间足够的卡片上使用，小幅按压反馈不改变布局尺寸。
5. 首页仍使用原图片加载器；颜色渐变为轻量背景，不新增模糊 / 折射、自动主题取色或海报网络来源。
6. 设置原 Java 协调者保留配置、弹窗、播放器选项、Hawk 写入和联动。Compose 只呈现值与派发原动作；单项 500ms 防重复确认，确认后保持焦点。
7. 原 mm / AutoSize 尺寸通过既有转换使用；不直接把 mm 数值改写为 dp。新字号和间距按 720p / 1080p 浅深色实测。

## 完成条件

- 首页与设置的浅 / 深色、720p / 1080p 截图可审阅；标题、值、胶囊、分组、焦点没有裁切或重叠。
- 顶部导航、首页到详情 / 原播放、设置类别 / 选项、原弹窗、返回焦点可用；设置动作与存储用固定样本验证，页面重建保留已有数据。
- 每组立即 Debug 编译；最终双 ABI、现有源与播放回归、包身份 / ABI / 空壳检查通过。
- 同设备、同内容对照最近已通过包的冷启动与 PSS，既有性能不足继续明确记录，不用新的视觉通过替代性能验收。
- 更新任务、交接、环境与本地提交；临时服务 / AVD / 构建中间产物验证后清理。远程写入按当前授权单独处理。
