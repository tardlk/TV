## 工作与验证

- [ ] 锁定支持 Android 9+ / ARMv7 的 Media3 与原生扩展组合；先验证 AAR / APK 和 JNI 实际加载。
- [ ] 通过现有播放接口接入候选内核，保留旧实现作为 Debug 对照和默认回退。
- [ ] 逐项核对请求头、重定向、proxy、嗅探结果、MP4 / HLS 等格式及字幕 / 音轨 / 倍速。
- [ ] 验证暂停、seek、自动下一集、换线与错误重试；对比旧实现，区分上游不可用与迁移回退。
- [ ] 保持 IJK / 外部播放器等功能；未有等价替代和设备证据时不删除 player 模块或旧选项。

## 完成条件

候选内核通过双 ABI 构建与真实路径验证后才成为默认；缺失功能和设备验收明确保留在清单中。
