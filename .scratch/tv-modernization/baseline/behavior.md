## 性能测量协议

在同一临时 AVD、同一分辨率与主题、空配置和相同 Debug 签名下，分别安装基线和候选，保留五次冷启动的 Activity 启动耗时与首个可操作 UI 检测时间、前台稳态 PSS，以及固定脚本滑动的 gfxinfo。启动前 force-stop，等待 boot completed；测试期间避免并发构建干扰。内存采样在首屏稳定后固定等待五秒。播放器单独用相同固定视频测时长、帧运动和退出资源。

首次启动权限 / 初始化单独记录，不混入五次统计。截图时钟和视频位置排除。20% 相对门槛是方案建议，只有实际完成两组测量后才给出通过 / 回退结论；模拟器结果不替代 ARMv7 真机性能。
