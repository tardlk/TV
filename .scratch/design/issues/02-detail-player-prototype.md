# 02：详情与播放控制层 HTML

Category: enhancement
Status: ready-for-human
Blocked by: 01（首页 C 已验收）

## What to build

沿首页 C 的配色、圆角、胶囊组件与信息层级，串联首页、影片详情、选集和全屏播放控制层，供用户评审。

- [x] 首页影片可进入对应详情，支持回首页。
- [x] 详情展示影片信息、收藏、线路、选集及播放入口。
- [x] 选集可进入播放预览，当前影片、集数与线路保持一致。
- [x] 播放控制层展示进度、播放暂停、上一集 / 下一集及选集入口。
- [x] 提供线路、倍速、字幕、音轨、更多参数的样式预览。
- [x] 保留浅深色、离线打开与空壳状态，不接真实播放、源或存储。
- [x] 完成浏览器截图和流程走查，交用户评审。
