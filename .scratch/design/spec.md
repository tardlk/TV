# TV：视觉原型

状态：需求已确认，首页 C 已选定；点播主流程与其余页面 HTML 已完成，待整体视觉评审。

## 已确认需求

- 新应用名为 TV，独立安装、独立数据，不迁移旧应用数据。
- 以 TVBoxOS 为底座和功能基准，FongMi/TV 按需作为成熟实现参考。
- 保留上游可用的播放、源兼容与遥控器逻辑；主要工作为 UI、布局与视觉调整。
- AVBox 是完整设计语言和 UI 风格的参考，不直接把手机版改成电视版。
- 系统兼容下限暂定 Android 9，必须支持 ARMv7；核心功能全部能用遥控器操作。
- 点播为主要场景；直播复用成熟功能和操作，视觉与全应用统一。
- 可舍弃模糊、透明叠层和复杂动效，优先排版、配色、形状、间距与清晰选中态。
- 使用顶部主导航，符合家人的使用习惯。
- 首页采用 C：顶部导航，上方主推荐采用大图与详情并列，下方展示继续观看。
- 正式应用为空壳，不预置站点、订阅或解析接口。
- 先用 HTML 确认界面，再进入 Android 实现。

## 本轮原型要回答的问题

已回答：用户于 2026-10-12 选择 C「主推荐与继续观看」。A / B 保留为本地比较资料，不同时作为正式首页模式。用户没有另行说明选择理由，不推断为新增功能或性能偏好。

## 原型范围

- 单个可离线打开的 HTML 文件：`prototype-top-nav.html`。
- C 为默认预览；A（推荐大卡与竖版海报行）和 B（分类与海报墙）保留供对照。
- 每个布局可切换暖色浅色 / 深色主题，以及示例内容 / 首次安装空壳状态。
- 只用内存保存设计预览状态，不接入真实源、配置、播放或用户数据。
- 图形海报、片名与观看记录均为虚构示例；原型未使用外部图片、字体或网络资源。
- HTML 原生按钮只用于浏览设计；不实现 Android 遥控器或焦点框架。

## 详情与播放控制层

用户于 2026-10-12 同意继续完成点播主流程。沿用首页 C 的视觉，不重新比较 A / B / C。

- 首页影片进入详情；详情展示预览画面、片名、简介、元信息、收藏、线路与选集。
- 详情播放入口或选集进入全屏播放预览；从播放返回详情，再返回首页。
- 播放层展示进度、暂停 / 播放、上一集 / 下一集，以及选集、线路、倍速、字幕、音轨和更多参数面板。
- 操作只更新示例内存状态；无真实视频、源访问、设备扫描、配置写入或 Android 播放逻辑。
- 使用 `page=home` / `detail` / `player` 在同一 HTML 中切换；参数可直接打开对应画面。
- HTML 只代表设计预览，不能据此宣称真实播放、源兼容、Android 性能或遥控器验收已通过。

## 其他页面

- 搜索：输入、快捷输入样式、最近搜索、样例结果和无结果；结果可进入详情。用户于 2026-10-12 确认键盘放在左侧，最近搜索、分类与说明放在右侧。
- 历史：记录与进度、继续观看、清空后的空态。
- 收藏：内容卡片、管理选择、删除所选及空态；收藏状态仅保留在预览内存中。
- 设置：配置与数据、播放设置、界面外观、关于；配置 / 文件 / 推送入口只展示界面，不读写真实数据或启动服务。
- 直播：频道列表、示例分组、节目条、线路与播放设置入口；没有直播流、真实 EPG 或按键实现。
- `state=empty` 下，搜索、历史、收藏和直播均不显示示例内容；设置仍可查看配置入口。
