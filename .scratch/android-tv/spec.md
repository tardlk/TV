# TV Android 首个可装机版本

用户于 2026-10-12 授权开工，测试订阅仅用于本地验证。

## 目标

从 TVBoxOS 建立独立的 TV 应用，在保留原源、播放和遥控器能力的前提下，落地 C 风格首页、详情、选集及播放控制层。Android 9+，包含 ARMv7；不迁移旧应用数据，正式 APK 不预置源。

## 顺序

1. 记录已有工具，配置项目专用构建环境，跑通上游 Debug 基线。
2. 配置独立身份、空壳默认值和 UI 资源。
3. 复用现有 Activity、Fragment、Adapter、播放器和点击 / 按键链，替换首页与点播 UI。
4. 构建 APK，核验 ABI、包名与无预置源；使用固定样本和用户订阅分层验证。

## 边界

不运行 Release、不发布或推送，不修改其他参考仓库。没有对应设备时，明确区分构建验证、协议验证和未完成的真机播放验证。

## 2026-10-12 首包结果

ARMv7 / ARM64 Python Debug APK 均构建、签名与包内容校验通过，安装包留在 artifacts。Android 11 ARM64 模拟器已验证空壳、配置导入、订阅首页 / 详情和自制 H.264 视频播放。生产配置未嵌入测试订阅。

核心 C 首页、详情、选集与播放器层已实现；搜索、历史、收藏、设置和直播的完整视觉统一仍需继续。ARMv7 实体电视及外部线路播放尚未完成验收。详见 docs/VALIDATION.md 与后续票 04。

## 后续路线规划

用户要求在保持当前 UI 的前提下制定 AVBox 式现代化方案。拟议路线与新任务见 [tv-modernization/spec.md](../tv-modernization/spec.md)；本文件继续记录首包现状，新方案尚未授权实施。
